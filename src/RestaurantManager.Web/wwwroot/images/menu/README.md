# Menu Item Images

This folder contains images for menu items.

## Image Naming Convention

Images should be named according to their menu item ID:
- `item-1.jpg` - Spring Rolls
- `item-2.jpg` - Garlic Bread
- `item-3.jpg` - Caesar Salad
- `item-4.jpg` - Soup of the Day
- `item-5.jpg` - Grilled Salmon
- `item-6.jpg` - Ribeye Steak
- `item-7.jpg` - Chicken Parmesan
- `item-8.jpg` - Vegetable Pasta
- `item-9.jpg` - Lamb Chops
- `item-10.jpg` - Chocolate Lava Cake
- `item-11.jpg` - New York Cheesecake
- `item-12.jpg` - Tiramisu
- `item-13.jpg` - Fresh Lemonade
- `item-14.jpg` - Iced Tea
- `item-15.jpg` - Espresso
- `item-16.jpg` - House Wine

## Image Specifications

- **Format**: JPG, PNG, or WEBP
- **Recommended Size**: 800x600 pixels
- **Aspect Ratio**: 4:3 or 16:9
- **File Size**: Keep under 500KB for optimal performance

## Placeholder Image

If an image is not available, the system will display a default placeholder with the food icon.

## How to Add Images

1. Place your food images in this folder
2. Name them according to the convention above (e.g., `item-1.jpg`)
3. The application will automatically display them
