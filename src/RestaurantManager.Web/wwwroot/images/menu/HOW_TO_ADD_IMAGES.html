??? How to Add Menu Item Images

Follow these simple steps to add beautiful images to your menu items

Step 1: Prepare Your Images

Collect or create images for each menu item. Recommended specifications:

  • Format: JPG, PNG, or WEBP
  • Size: 800x600 pixels (or any 4:3 ratio)
  • File Size: Under 500KB for best performance
  • Quality: High resolution, well-lit, appetizing presentation

Step 2: Name Your Images

Rename your images using this convention:

item-1.jpg - Spring Rolls
item-2.jpg - Garlic Bread
item-3.jpg - Caesar Salad
item-4.jpg - Soup of the Day
item-5.jpg - Grilled Salmon
item-6.jpg - Ribeye Steak
item-7.jpg - Chicken Parmesan
item-8.jpg - Vegetable Pasta
item-9.jpg - Lamb Chops
item-10.jpg - Chocolate Lava Cake
item-11.jpg - New York Cheesecake
item-12.jpg - Tiramisu
item-13.jpg - Fresh Lemonade
item-14.jpg - Iced Tea
item-15.jpg - Espresso
item-16.jpg - House Wine

Step 3: Place Images in the Menu Folder

Copy your renamed images to:
wwwroot/images/menu/

Step 4: Update Database (One-Time)

After stopping your application, run these commands:

dotnet ef migrations add AddMenuItemImages --project src/RestaurantManager.Infrastructure --startup-project src/RestaurantManager.Web

dotnet ef database update --project src/RestaurantManager.Infrastructure --startup-project src/RestaurantManager.Web

Step 5: Restart and Enjoy!

Start your application and your menu items will display with beautiful images!

?? Note: If an image file is missing, the system will automatically display a placeholder icon instead. This ensures your menu always looks good even without all images.
?? Pro Tip: You can find free food images on sites like Unsplash, Pexels, or Pixabay. Search for terms like "spring rolls", "salmon dish", "cheesecake", etc.
